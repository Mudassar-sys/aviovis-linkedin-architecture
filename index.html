LinkedIn Operations Architecture

Technical Infrastructure for 100+ Profile Workspaces

Prototype v1.0 For Aviovis Group

Architecture Overview

Workspace operations control plane for up to 100 assigned workspaces, with capacity model to 250 and 500 after legal/identity feasibility confirmed. Three counts matter: N = registered workspaces (100/250/500), C = peak simultaneously active (measure in pilot), U = human operators (not equal to N).

Owner-Led Authentication Model
LinkedIn User Agreement prohibits using another person's account via shared credentials or cookies. Infrastructure team manages hosts, not LinkedIn credentials. Profile owners handle their own login, 2FA, verification and appeals personally.
5
Central Dashboard
Web-based with owner/operator/admin views. Shows workspace host health with provenance. Does not show live LinkedIn account status (no authorized feed). Statuses: WORKSPACE_READY, OWNER_ACTION_REQUIRED, INFRA_DEGRADED, SESSION_STATUS_NOT_VERIFIED, OWNER_REPORTED_RESTRICTED.
4
Security and Access Control
RBAC with 5 roles. Infrastructure secrets in managed vault. Personal LinkedIn credentials stay with owner only. Audit log with evidence source.
3
Network Connectivity
Corporate remote access via WireGuard VPN. Proxy decision is conditional (job asks whether needed). Three options: no proxy, residential proxy where approved, ISP static proxy.
2
Browser Workspace Isolation
Workspace management tool (GoLogin, Multilogin or alternative). Each workspace uniquely configured. Clear owner involvement points for login, re-auth, 2FA, verification.
1
Cloud Hosting
Hetzner Cloud EU (Finland/Germany), closest to Lithuania. OS decided in pilot. Batch scheduling: profiles do not all run simultaneously.

Role-Based Access Control

5 roles with clear separation between infrastructure management and LinkedIn account actions. Infrastructure team manages hosts, not personal LinkedIn credentials.

Infrastructure Admin
Can Do
Host/OS patching and updates
Health metrics monitoring
Workspace provisioning
Platform service recovery
Network/proxy configuration
Backup management and restore
Cannot Do By Default
Sign in as LinkedIn member
Extract cookies or 2FA seeds
View LinkedIn message content
Appeal account restrictions
Operations Lead
Can Do

View full attention queue
Approve operational changes
Generate reports and exports
Cannot Do By Default
Override owner access decisions
View unrelated workspace data
Modify infrastructure settings

Can Do

Use approved tools within workspace
Report issues through queue
Cannot Do By Default

Export credentials
System administration
Account Holder / Owner
Can Do

Cannot Do By Default

Auditor

Delete audit records
